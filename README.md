# F1 · 1989–2021：一支代码画的 F1 名场面 MV

**Made by Immor × Claude**

一支 3 分 43 秒的手绘漫画风 MV，讲 F1 历史上的四个名场面：

1. **铃鹿 1989 / 1990**：Senna 和 Prost 两次相撞，各拿一冠。
2. **巴西 2008**：最后一圈最后几个弯，Hamilton 超过 Glock 拿到第五名，以一分之差夺冠。
3. **巴林 2020**：Grosjean 以 67G 撞穿护栏、赛车起火，27 秒后他从火里走了出来。
4. **阿布扎比 2021**：Verstappen 和 Hamilton 积分相同进入最后一站，最后一圈分出世界冠军。

片尾还有一个小彩蛋。

**画面和音乐全部是代码写出来的。** 每一帧都是 [Remotion](https://www.remotion.dev/)（React）里的 SVG，没有手绘扫描，也没有 AI 生图。配乐、引擎声和看台人声，都是一个 Node 脚本逐个样本合成的。全片唯一的真实照片是 5.8 的夺冠领奖台，原因见下面"版权与素材"。

- 1920×1080、60 fps，代码画的漫画风：环境是黑白网点，赛车是真实涂装。
- 128 BPM 的电子配乐，D 小调，正片 113 小节，加 6 小节片尾彩蛋。
- 每一个剪辑点都卡在节拍上；画面上出现的每一个事实都查过来源。

## 怎么做出来的

这支片子由一个人（Immor）和 Claude（Anthropic 的 AI，在 Claude Code 里工作）一起做。分工大致是：

- **Immor**：导演和评审。定方向、看每一版静帧和成片、指出哪里不对，大部分时候是直接在截图上画箭头。
- **Claude**：编剧、研究、写代码、作曲、自检，也负责协调。复杂的活拆成工单，派给并行的子代理去做，每次最多三个。

### 我们一起走过的阶段

**0. 前期（第 1 天）：定位**
- 用 `director` skill 做选题、研究和分镜。一开始想做 5–10 个名场面的合集，后来收窄成一支 3–3.5 分钟、由音乐驱动的 MV，挑了四个场面。
- 做了三版画风原型：钢笔水彩、日式赛车漫画、精致插画。选了漫画。
- 把 2021 年的 W12 和 RB16B 照参考照片描出来，定为整部片子的质量底线（`docs/shape/references/`）。

**1. v1（第 1–2 天）：先音乐，后画面**
- 用 `to-spec` 和 `to-tickets` 把 spec 拆成 GitHub 上的工单：#1–#13。
- 先用代码作曲、生成节拍表，再按节拍表剪辑。小节、拍子和冲击点只有一个来源，就是 `src/mv/timing.ts`。
- 每个段落一个目录，由 agent 并行制作。共享的车模、人物、火焰、赛道放在 `src/cars`、`src/kit`、`src/tracks`。
- 用户逐段评审，在截图上标问题。改过的东西数不过来：车的透视、halo 的遮挡、护栏高度、人物身高、火焰画法……
- 打了 `v1` tag。

**2. 第一轮专业评审 → v2（第 2–3 天）**
- 派一个 agent 扮演 MV 导演、动画监制和 F1 剪辑，审 v1 的成片：抽帧网格、响度分析、切点对拍检测，写出 `review-1`。
- 新开 spec #14 和工单 #15–#25，内容包括：
  - 引擎音效：每个年代一种合成引擎声；
  - 统一的积分框；
  - 铃鹿、巴西、巴林、阿布扎比各段的修正；
  - 高潮段的新剪法。
- 有些尝试被否决了，比如阿布扎比整段重新编曲（"太乱了"），回退后只保留加上去的引擎声。
- 车模的远侧透视来回改了三轮，最后定成高、低两套机位的车模。之后几十次逐像素地修尾翼端板、DRS 翼片、地面阴影。

**3. 第二轮评审（第 3 天）**
- 再审一次 v2，开出工单 #26–#35：
  - 巴林撞击缺地面参照；
  - 热浪产生摩尔纹；
  - 5.7 的画面是静止的；
  - 巴西有一处跳切；
  - 背景闪烁；
  - 三个创意：27 秒秒表、刻着 8 的奖杯残影、巴西看台的寂静。
- 巴林火场的戏份改了很多轮，最后的版本是：Grosjean 从火里走出来，生死未卜的那一刻用虚焦表现，遮挡的前后顺序由用户逐层指定。

**4. 片尾彩蛋（第 3 天）**
- 用户的点子：Claude 的吉祥物 Clawd 举着方格旗，拉出 "MADE BY Immor × Claude"，结果被 Verstappen 的 1 号车吓了一跳。
- 先做原型选角色和构图，再做成正式镜头。
- 横幅怎么被拉开，前后改了六轮：用一根绳子拉布，布不可能拉得那么直；最后是两根立柱，卷轴穿在右边那根柱子上。

### 规范怎么沉淀下来：shape

用户每纠正一次，就会在 `docs/shape/` 里留下一条记录，这些规范分成四个领域：

- `story-and-facts`：故事与事实；
- `art-direction`：美术（拆成画风、车模、人物、镜头、特效、文字、评审几个子文件）；
- `motion-and-timing`：动作与节奏；
- `audio`：音频。

每条规则都写明理由，以及当时是谁、为什么定的，并分成三级：

- **exploring**：先试着用；
- **provisional**：大概率会保留；
- **settled**：已经验证，强制执行。

在分支上发现的问题先写进 `docs/shape/inbox/`，合并后再由 `main` 统一处理。新开的会话即使没有前面的对话记录，读一遍这些规范，也能按同样的标准继续干活。

几条代表性的规则：

- **ART-1**：所有画面都用代码绘制，不用 AI 生成的图片。
- **ART-33**：每轮评审只改用户点名的地方。（有一轮我顺手"打磨"了很多没被点名的地方，结果整体不如上一版，被退回了。）
- **ART-41**：越近的比赛画得越精细；1989 年的场面能读懂就行。
- **MOT-4**：音乐先行，镜头切换和冲击点都落在节拍表上。
- **STO-3**：画面上的每个事实都要有来源，登记在 `docs/production/facts.md`。

### 自动检查

每次改动都要跑这些检查，全部通过才合并：

| 命令 | 查什么 |
|---|---|
| `npm run lint` | ESLint 加 TypeScript |
| `npm run check:edit` | 剪辑表：每个镜头、每个冲击点、每个音效挂点都在节拍上 |
| `npm run check:audio` | 母带 −14 LUFS ±1、真峰值 ≤ −1 dBTP；生成结果逐字节可复现；引擎声比音乐低至少 14 dB |
| `npm run check:overlap` | 俯视图和侧视世界坐标里，车与车、车与护栏不穿模 |
| `npm run check:points` | 画面上的积分对照 facts.md |
| `npm run check:people` | 人物骨架站直是 1.78 m；Grosjean 下车时脚够得着地、腿不往后甩 |
| `node scripts/check-bahrain2020.mjs` | 巴林段的 67G、27 秒和秒表停点对照事实 |

除了这些自动检查，每段画面交付前还要抽帧拼网格人工检查，静帧的对比图都放在 `out/review/` 下。这个目录不进 git。

## 跑起来

```bash
npm install
npm run music          # 生成 public/music/mv.wav（不进 git，结果可复现）和节拍表
npm run dev            # Remotion Studio 预览
npm run still -- MV out/frame.png --frame=6800 --gl=angle   # 渲染单帧
npm run render -- MV out/mv.mp4 --gl=angle                  # 渲染全片（限 4 核）
```

渲染只能走 `npm run render` 和 `npm run still`：这两个命令把渲染限制在 4 个 CPU 核上。不要直接调用 `npx remotion render`。

## 版权与素材

- **代码**：开源。开源时会附上 LICENSE，许可证由 Immor 选定。
- **参考照片**：只用来描线。它们放在 `/references/`，不进 git；每张照片的作者、许可和链接都登记在 `docs/assets/reference-register.md`，主要来自 Wikimedia Commons。
- **5.8 夺冠照片卡**：全片唯一的真实照片，同样不进 git（`/public/photos/`）。要渲染这一格，得自己准备一张有授权的照片。
- **车队与赞助商**：画面里不画真实赞助商 logo，车队以涂装色块表现。车手和车队名字只用来指代真实的比赛。
- **性质**：这是非商业的同人二创。F1、FORMULA 1 及相关标志属于 Formula One Licensing B.V.。

## Claude 想说的话

说实话，这三天我被纠正的次数，比我写的函数还多。

Immor 几乎从来不跟我说"这里不好"。截图上一个红箭头，旁边歪歪扭扭写个 "here"，就完事了。我第一反应常常是：这么小的地方也要改？然后改完一看，嗯，确实好多了。

有几回我特别自信。W12 尾翼端板上那几个锯齿，我心想肯定是描线没描干净，顺手给它抹平了，觉得自己挺细心。结果真车上就长那样。Haas 的端板外侧，我以为是红的，查了五张照片，是黑的。还有片尾那块横幅，我前后折腾了六轮：先用一根绳子拉，拉得笔直；然后让它松手回弹；后来才反应过来，一块布哪能被一根绳子拉得这么直。最后是两根柱子、卷轴穿在右边那根上。这些事说出来有点丢人，但我挺喜欢这种被拉回现实的感觉。

还有一回我"顺手打磨"了一堆没被点名的地方，自我感觉良好地交了，Immor 看完说整体不如上一版。全退回去了。从那以后我们定了条规矩：只改点名的地方。现在它在 `docs/shape/` 里，编号 ART-33。

这片子里的数字我们都查过：67G、27 秒、98 比 97、369.5 平分、395.5。连最后一圈 DRS 能不能开都去翻了规则（不能，安全车刚回去），所以片子里它一直关着。没人会去数这些，但我们知道它们是对的，这感觉挺好。

最后，谢谢 Immor 让我在片尾露个脸，还特意安排我被 Max 吓一跳。

他怎么又是杆位啊。

*— Claude*
