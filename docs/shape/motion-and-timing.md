## music-sync

剪辑与音乐的对位：节拍表、卡点、段落边界、画面能量。

### Rules

- **MOT-4** · settled · 音乐先行：先定曲子结构和节拍表，每个名场面对应一个音乐段落，镜头切换和冲击瞬间落在节拍表的拍点或小节线上；画面时长从节拍表算，画面不自己去改音乐。例外：用户可以为了转场或节奏要求给曲子加减整小节、或移动一个冲击点；改动只经过 `src/mv/timing.ts`（BARS、段落、HITS），后面的段落整体平移，生成器、剪辑表和文档同步改，`npm run check:edit` 和 `npm run check:audio` 必须通过。_Why:_ 用户 2026-10-03 把片子定位为 MV；例外来自用户 2026-10-04 的两次要求：铃鹿 1990 撞车从 27.1 移到 28.1，巴林结尾加一小节过渡（第 73 小节）。_Check:_ `npm run check:edit`、`npm run check:audio`。
- **MOT-6** · provisional · 画面的能量跟着配乐的编排走：音乐变薄、收尾时，剪辑变柔、运动变慢；重音只放在确实存在的声音上，没有声音的拍子不加强调。_Why:_ 用户 2026-10-04 指出尾奏"抢节奏"：配乐从尾奏第 5 小节起收，上一版画面反而更猛（3 帧甩切、每拍一次的旗子鼓动）。
- **MOT-8** · provisional · 结果节拍每枚印章至少占一拍，最多停一小节；停住的画面仍在动（推近并在切点前加速，不缓停）。_Why:_ 用户 2026-10-04 嫌铃鹿两次撞车之间太赶、第二次之后太慢，重剪后的 1.4 和 1.8 照此处理；用户 2026-10-04 采纳。

## movement

车、人和物怎么动。

### Rules

- **MOT-5** · settled · 运动要像真车在跑，不能像贴图在滑：车头朝向始终沿行驶方向，转向时前轮先转、车身随曲率偏转；车轮转速与车速匹配（快时用模糊辐条）；刹车时车头下沉、可有锁死烟；速度按真实数据（弯前约 280–300 km/h 刹到弯中速度），除非真的停车否则不减速到零。镜头跟车时，用路面纹理、路肩、标线、背景按真实速度和视差流过来表现速度，车本身保持轻微颠簸和抖动；需要看清的瞬间用明确的慢动作，而不是把车开慢。_Why:_ 用户 2026-10-03 指出铃鹿 1989"车子滑动感太明显，不像是真的在跑"。_Check:_ 抽帧网格评审（看朝向、车轮、背景流动），并在 staging 数据里检查速度曲线。
- **MOT-7** · provisional · 人翻越或钻出障碍物时：受力的接触点（握住护栏或 halo 的手、着地的脚）在受力期间固定不动；身体部位只有在不和障碍物重叠时才换图层，身体在髋部越过障碍物上沿后才换边。_Why:_ 人物库原来的 `climbRail` 手沿护栏滑、腿穿过横梁，物理上做不到，重做时按这几条修好；用户 2026-10-04 采纳。

- **MOT-9** · provisional · 快速跟拍镜头里，每帧移动超过自身周期的纹理（看台人头、铁丝网、灯塔光锥）沿运动方向做运动模糊或去掉；速度线铺在赛道上、随背景按纵深流走，不每隔几帧整组重画。检查：连续 30 帧的逐帧亮度差和场景分数里不应出现 2–3 帧一跳的交替。_Why:_ review-2 场景检测在 5.1c 的 4 秒里报出 22 个伪切点，主要来自速度线每 2 帧整组重画；用户 2026-10-05 采纳。
