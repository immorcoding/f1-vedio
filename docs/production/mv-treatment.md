# MV 前期方案（treatment）

状态：草稿，待用户确认。

一支 3 分 30 秒的手绘漫画风 F1 MV，没有旁白。原创电子乐是骨架，四个名场面按时间顺序排开，2021 阿布扎比是高潮。规则见 `docs/shape/`，事实及来源见 `facts.md`。

## 音乐骨架

- 速度 128 BPM、4/4 拍：1 小节 = 1.875 秒 = 112.5 帧（60 fps）。
- 全曲 112 小节 = 210 秒。所有镜头时长都以小节计；冲击瞬间落在小节线或强拍上（MOT-4）。
- 调性贯穿全曲不变；各段只改变配器密度和能量。

## 对素材计划（issue #1）的影响

- 素材范围不变：四个名场面的车、赛道局部、场景背景、特效、漫画版式都还需要。
- 新增：发车灯（前奏）、积分翻牌卡、分屏和多格版式、头盔对望特写、方格旗。
- BGM 从"可拼接的多段 cue"改为一首 3:30 的完整曲子，段落和小节数按上表；节拍表照常输出。
- 1989 和 1990 的铃鹿素材都要做；镜头 1.8 和 6.2 需要不同年代的头盔。
