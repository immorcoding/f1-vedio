# MV 前期方案（treatment）

状态：草稿，待用户确认。

一支约 3 分 32 秒的手绘漫画风 F1 MV，没有旁白。原创电子乐是骨架，四个名场面按时间顺序排开，2021 阿布扎比是高潮。规则见 `docs/shape/`，事实及来源见 `facts.md`。

## 音乐骨架

- 速度 128 BPM、4/4 拍：1 小节 = 1.875 秒 = 112.5 帧（60 fps）。
- 全曲 113 小节 = 211.875 秒。所有镜头时长都以小节计；冲击瞬间落在小节线或强拍上（MOT-4）。
- 全曲 D 小调，不转调；各段只改变配器密度和能量。巴林结尾的第 73 小节是过渡小节：长 pad 落回主和弦 Dm 并自然衰减，心跳最后一下（较轻）落在 73.1；73.3 起一段反向渐强（滤波噪声加倒放的 Dm pad）升起，74.1 平滑接进蓄力的 riser，没有和声上的跳变。这一小节是 2026-10-04 应用户要求加的（巴林结尾切黑太突然），之后的段落整体后移一小节；同日用户嫌 73.3 转 A 大调太突兀，改成现在的延续式过渡。

## 音效（引擎声，#15）

音效轨是独立生成、混在音乐下面的引擎声（`src/mv/sfx.ts` 挂点，`scripts/lib/engine.mjs` 合成，事实见 `facts.md`"引擎声"）。每个挂点都在有车的镜头里（`npm run check:edit` 检查），每一小节都比音乐低至少 14 dB（2.2 雨中 17 dB；`npm run check:audio` 要求至少 12 dB）。用户 2026-10-04 听了 #15 嫌引擎太响、盖过音乐，整条音效轨降了 6 dB。车按画面里的车速驱动：加速升档、刹车降挡补油、收油回火；画面慢动作时声音同样变慢变暗。
